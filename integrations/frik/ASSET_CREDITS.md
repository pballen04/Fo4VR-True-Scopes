# FRIK menu assets

The shared button meshes and the templates used for the calibration meshes
come from the [FRIK UI assets](https://github.com/rollingrock/Fallout-4-VR-Body/tree/744c22e32e2cb513ae2c715ace4199a07a27fb24/data/mod/Meshes/FRIK).
FRIK is copyright © 2021 Jason Pharis and contributors and is distributed
under [GPL-3.0](https://github.com/rollingrock/Fallout-4-VR-Body/blob/744c22e32e2cb513ae2c715ace4199a07a27fb24/LICENSE).
The shared meshes use the `Textures/FRIK/ui-common.DDS` atlas supplied by FRIK.

The calibration launcher, title, and layout use the companion's own atlases.
The title and layout artwork adapt FRIK's UI sprites. The custom meshes were
packed with the [F4VR-CommonFramework VRUI atlas tool](https://github.com/ArthurHub/F4VR-CommonFramework/blob/3f0bbc8c45c1193b16ca1c09b9f8ba2a97b95890/nif-tools/vrui_atlas.py).
The editable texture atlases are stored as uncompressed RGBA DDS files.
